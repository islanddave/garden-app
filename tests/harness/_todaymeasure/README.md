# `_todaymeasure` — the Today page's measurement instrument, promoted

Until 2026-09-08 this directory was **untracked scratch in a sibling worktree**, and the lane that
built it called it "safe to delete". It is the only instrument that has ever measured the Today page
in real Chrome, and the entire evidence base for the Today redesign crucible rests on it. A redesign
measured against a deleted instrument is unmeasured, so it is now tracked, scrubbed, and wired.

## What is here

| file | what it is |
|---|---|
| `../todaymeasure.html` + `../todaymeasure.jsx` | mounts the **real** `src/pages/Today.jsx` inside the **real** `AuthProvider` and `MemoryRouter`. Nothing under `src/` is re-implemented; only `window.fetch` is stubbed, at the wire. |
| `drive.mjs` | the **recorder**. Drives real headless Chrome at a CDP-emulated 390×844 and writes a full capture + screenshots to `out/`. Asserts nothing; it records. |
| `analyse.py` | turns a capture into the section / whitespace / type / control tables. |
| `today-shape-budget.json` | **the baseline**, generated by `npm run gate:today-shape:record`. Every number in it is a real `getBoundingClientRect` / `Range.getClientRects` reading. |
| `bands-notes.md` | per-endpoint provenance for the fixtures: the exact SQL, the row counts, the caveats. |
| `*.json` | the fixtures — dumped from live Neon as the read-only `garden_ro` role for 2026-09-08, then **scrubbed** (below). |

The **gate** built on top of it is `scripts/layout-gate/today-shape.mjs` (`npm run gate:today-shape`).
The recorder and the gate are deliberately different programs: the recorder characterises and the
gate refuses, and conflating them is how a gate ends up re-recording its own baseline to go green.

## The fixtures are scrubbed, and exactly how

`scripts/layout-gate/todayshape-fixture-scrub.mjs` is the one-way transform from a raw dump to a
trackable fixture. It rewrites two classes and **nothing else**:

- every `user_[A-Za-z0-9]{10,}` → a pseudonym assigned by frequency across the whole corpus. The
  most frequent (342 occurrences) becomes `harness_user`, which is the id the harness Clerk stub
  serves — not cosmetic, because `ComposeHarvestBand` scopes its batch to the **viewer**, so a
  fixture whose `created_by` is anything else renders a 0px band and the instrument silently
  measures 65px less page than it claims to.
- every `lat`/`lng`/`lon`/`latitude`/`longitude` key → the single declared synthetic site
  (39.8283 / −98.5795, the geographic centre of the contiguous US). Rounding a residence coordinate
  is not scrubbing it.

**Real plant names, cultivar names and location paths are deliberately kept.** They are
horticultural rather than credential-shaped, they are already throughout the repo's own tracked
tests (`git grep "Bag Area" -- src/__tests__` returns ten files), and they are load-bearing for what
is being measured: label length drives row height, group-header wrapping and the ellipsis in `Row`.
Replacing them with lorem would silently change the geometry this instrument exists to pin.

`scripts/layout-gate/todayshape-fixture-preflight.mjs` is the guard, not the scrub. It runs as its
own CI step, as step 0 of the gate, and it carries `--self-test`, which fires every matcher against a
known positive built inside the file (never sampled from the corpus it guards) and exits 1 unless all
of them fire.

## The baseline, measured 2026-09-08

Real Chrome, CDP-emulated 390×844 `mobile:true`, DPR 2, clock pinned to `2026-09-08T15:54Z`,
timezone `America/New_York`, Open-Meteo stubbed at the wire.

| state | scrollHeight | content ends | ink % | care rows | groups | expanded | controls | 1st control |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| `busyfull` | **6,232px** (7.38 viewports) | y=6,192 | 54.7 | 70 | 9 | 1 | 261 | y=456 |
| `busy` | 6,153px (7.29) | y=6,113 | 54.8 | 70 | 9 | 1 | 260 | y=456 |
| `quiet` | 844px (1.00) | y=510 | 29.5 | 0 | 0 | 0 | 1 | y=478 |
| `noplan` | 844px (1.00) | y=325 | 21.2 | 0 | 0 | 0 | 1 | y=294 |

These reproduce `_lane-todaymeasure-20260908.md` **exactly** — 6,232px, 54.7% ink, 70 rows, first
control at y=456 — which is the cross-check that pinning the clock and stubbing the weather changed
the determinism and not the page.

### Two numbers the harness cannot see, asserted anyway

The harness mounts `Today` alone. Production adds a 52px in-flow sticky `TopChrome` and a 56px fixed
`BottomNav`, so the real document is ≈108px taller and only **736px** of the 844px window ever shows
page content — making `busyfull` **8.61 usable-window-heights**, not 7.38. Both constants are
carried in the gate and printed on every run, so a nav-height change invalidates the budget loudly.

### `scrollHeight` is clamped, and the floor that is not

A document is never shorter than the viewport, so on `quiet` and `noplan` (both exactly 844px) a
scroll-height floor is **vacuous** — a completely blank page satisfies it. That is why the gate also
records `contentBottom`, the y of the last row on which anything paints (510 and 325). That is the
floor that bites on the short states.

## Re-running

```
npm run gate:today-shape                  # the gate — refuses, exits non-zero
npm run gate:today-shape:probe-nothing    # proves the gate can fire; MUST exit 1
npm run mutate:today-shape                # 14 real defects; each must red the gate (~10 min)
npm run gate:today-shape:record           # re-record the baseline. Deliberate act, never a fix.
npm run todaymeasure -- --states busy,busyfull,busyhh,quiet,noplan   # the recorder + screenshots
python3 tests/harness/_todaymeasure/analyse.py tests/harness/_todaymeasure/out/measure-busy.json
```

`busyhh` (the household lens, +815px) is measurable by the recorder but is **not** in the gate's
budget: it doubles the run and the four states above already cover the has-plan, empty-plan and
no-plan shapes. Add it with `TODAY_SHAPE_STATES=…,busyhh npm run gate:today-shape:record`.

## The viewport is 390, and that is an open question

390×844 is an iPhone preset. Dave is Android-only and the only device width this repo records is
412px. The gate pins 390 because that is the width the existing evidence base was measured at, so the
baseline and the crucible describe the same page — **not** because 390 is known to be the target.
Re-pointing it is one edit to `VIEWPORT` in the gate plus one `--record`; the refusal reads the
constant, never a literal.
